# Flashcards Generator

Simple local app that creates study flashcards from pasted text using the OpenAI API.

Quick start:

1. Install dependencies

```bash
npm install
```

2. Start server

```bash
npm start
```

3. Open http://localhost:3000 and paste your OpenAI API key and text, then click Generate.

Notes:
- This app requires an OpenAI API key. You can use free trial keys if available.
- The key is sent from the browser to the local server and then to OpenAI. Keep keys private.
